# Reference capture tools

Runtime qualification uses the [regression runner pre-merge lanes](../regression/README.md).

`gliden64-reference-capture.sh` captures a content reference using the batch
stdin adapter. `compose-reference-pair.py` composes labeled review images.
GLideN64 images are for visual content judgment; they must not enter digest
or similarity gates. Run each tool with `--help` for explicit input options.
